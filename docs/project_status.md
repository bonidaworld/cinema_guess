# Актуальный статус CinemaGuesser

Дата актуализации: 11 ноября 2026 года.

## Текущее состояние

CinemaGuesser — рабочий однопользовательский браузерный прототип игры на угадывание позиции кадра фильма. Реализован игровой цикл из пяти раундов: меню с WebGL-фоном, загрузка кадра, выбор позиции на временной шкале, серверная проверка, начисление очков и итоговый экран.

Приложение использует PostgreSQL через пул `pg` и `DATABASE_URL`. Игровые API читают готовые записи из `app.v_frames_ready`. Правильный таймкод не отправляется при выдаче раунда: он читается сервером при проверке ответа. Изображения WebP отдаются API-маршрутом из локального каталога `FRAMES_WEBP_DIR` с проверкой пути.

Схемы разделяют импортированные записи (`ingest`), сведения и сопоставления фильмов (`imdb`), канонические кадры и ассеты (`core`), а также представление для игры (`app`). Python-скрипты поддерживают обновление базы, преобразование исходных изображений в WebP, логирование и резервное копирование. Описание процесса находится в [`db_pipeline.md`](db_pipeline.md) и [`scripts/README.md`](../scripts/README.md).

Старые массивы `data/movies.ts` и `data/frames.ts` остаются в репозитории, но игровые API их не используют. WebP-ассеты не хранятся в Git и должны быть доступны локально вместе с настроенной базой. В статусе от 2 августа 2026 года указано 1239 зарегистрированных кадров, из которых 1195 проходили условия `app.v_frames_ready`; это исторический снимок локальной БД, а не проверенное текущее количество.

## Что работает

- `GET /api/round` выдаёт случайный готовый кадр без правильного таймкода и принимает исключаемые ID для предотвращения повторов в браузерной игре.
- `POST /api/guess` проверяет диапазон ответа, получает правильную позицию из базы и считает результат.
- `GET /api/frame-image/[framePublicKey]` выдаёт соответствующий WebP-файл из разрешённого каталога.
- Интерфейс поддерживает загрузку, ошибку с повторной попыткой, блокировку повторной отправки, результаты раундов и сумму очков.
- Резервное копирование базы и обработка локальных ассетов поддерживаются скриптами в `scripts/`.

## Незавершённые задачи и ограничения

- Нет автоматических тестов для подсчёта очков, API, связей данных и полного игрового сценария.
- Нет постоянных серверных игровых сессий: список использованных кадров хранит и присылает браузер.
- История и очки не сохраняются; нет аккаунтов и leaderboard.
- WebP-файлы не вынесены во внешнее объектное хранилище.
- В игре нет filmstrip или миниатюр временной шкалы.
- Не подтверждены происхождение и права на используемые кадры; текущие материалы следует считать прототипными.
- Настройка и воспроизводимый запуск базы и локальных WebP зависят от среды разработчика.
