# Инструкции для CinemaGuesser

## Стек и структура

- Next.js 16 App Router, React 19, TypeScript (`strict`), Tailwind CSS 4; интерфейс и игровые API находятся в `app/`.
- PostgreSQL подключается через `pg` из `src/lib/db.ts`. Игровые API используют `app.v_frames_ready`; SQL для схем и view лежит в `db/`.
- WebP-кадры хранятся вне Git и обслуживаются маршрутом `app/api/frame-image/[framePublicKey]/route.ts`; нужны `DATABASE_URL` и `FRAMES_WEBP_DIR`.
- Подготовка БД и ассетов: Python-скрипты в `scripts/`. Игровая формула — `lib/scoring.ts`.

## Правила изменений

- Соблюдай KISS, DRY и YAGNI: предпочитай прямое решение, не дублируй логику и не добавляй абстракции или функции без текущей необходимости.
- Игровые правила согласованно меняй в интерфейсе (`app/page.tsx`) и API. Сейчас игра длится пять раундов; не допускай расхождения счётчика и переходов.
- `GET /api/round` не должен раскрывать правильный таймкод. Проверяй ответ и вычисляй результат на сервере в `POST /api/guess`; не переноси правильный ответ в браузер.
- Валидируй входные данные API и используй параметризованные запросы PostgreSQL.
- Обновляй относящуюся к изменению документацию: запуск и назначение — `README.md`, состояние и ограничения — `docs/project_status.md`, подробности вертикального среза — `docs/slice.md`, настройка приложения — `docs/app_steps.md`, DB и ассеты — `docs/db_pipeline.md` и `scripts/README.md`.
- Перед правками проверь `git status` и diff. Сохраняй существующие незакоммиченные и staged изменения; не откатывай и не перезаписывай чужую работу.

## Проверки и команды

В `package.json` доступны скрипты `dev`, `build`, `start` и `lint`; тестового скрипта сейчас нет. Запускай уместные проверки после изменения кода:

```powershell
npm.cmd run lint
npm.cmd run build
```

Для локального запуска используй `npm.cmd run dev`. В PowerShell `npm.cmd` позволяет обойти блокировку `npm.ps1` без изменения политики выполнения.

Скрипты обработки данных описаны в `scripts/README.md`; запускай их только для задачи, связанной с подготовкой БД или ассетов.
